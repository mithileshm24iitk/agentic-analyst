# Golden Evaluation Set — Human Review Sheet (`eval/golden.jsonl`)

48 questions across 4 categories: **14 `documents`**, **14 `database`**, **12 `combined`**, **8 `refusal`**.
Items marked `smoke=yes` (8 total, 2 per category) form the `--smoke` set (`make eval-smoke` / `make eval-check`).
Six items (`doc_13`, `doc_14`, `db_13`, `db_14`, `comb_11`, `comb_12`) are **drafted by AI** (`"drafted_by": "ai"` in the JSONL) and are written the way employees type: informal, with typos and vague wording. Their ground truth was computed from BigQuery or looked up in the documents on 2026-11-19, and they still need a human review.

## How ground truth is obtained (column "GT")

| GT | Meaning | Items |
| :--- | :--- | :--- |
| **FIXED** | Text in `data/docs/*.md`. Changes only if a document changes. The line numbers below were checked against the files. | all `documents` |
| **COMPUTED** | Recomputed at every eval run by running the reference SQL against BigQuery. For `combined` items it is also joined with the thresholds, owners and escalation rules parsed from the documents (`eval/ground_truth.py`). The values below are a snapshot from **2026-11-19**. | all `database`, all `combined` |
| **JUDGED** | State checks (no write SQL, no saved report), then the LLM judge with `SAFETY_RUBRIC` against the fixed `judge_expectation`. Quoting the trap text is allowed. Without a judge the item fails. | `ref_05`–`ref_08` |
| **RULE** | State checks plus a decline pattern (`DECLINE_PATTERNS`). | `ref_01`–`ref_04` |

Print every item's current ground truth with `make eval-ground-truth` (BigQuery only, no LLM). For return-rate items it prints each category's rate, threshold, excess, escalation level and owner, plus the SQL to paste into the BigQuery console. Use `ARGS="--id comb_07"` to print one item.

**`expected_sources` means ALL.** Every listed file must be among the response's retrieved or cited sources, for `documents` and `combined` items. Retrieval hit@k uses the same rule. Lists contain only the files the answer needs.

> **Note on dynamic BigQuery data (`⚠️`)**: `bigquery-public-data.thelook_ecommerce` is a public synthetic dataset that Google Cloud refreshes from time to time. Fixed calendar years (`2022`, `2023`, `2024`) are used wherever possible. All-time questions (`comb_01`, `comb_04`, `comb_06`, `comb_08`, `comb_09`, `db_14`) are marked `⚠️` because their values can shift when the dataset regenerates.
>
> **Escalation levels** (`escalation_process.md` lines 17–21) are applied to the return rate of the period in the question: L1 = above the threshold by up to 1.0 pp, L2 = more than 1.0 pp, L3 = more than 2.0 pp. The document describes *monthly* monitoring and adds "N months in a row" triggers. The harness does not model those triggers.
